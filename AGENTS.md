# AGENTS.md

Roastronaut is a DIY coffee roaster built in four phases, and the docs are the deliverable. Start at [docs/README.md](docs/README.md) for cross-cutting reference, or [docs/phases/README.md](docs/phases/README.md) for the phase plan.

## Agent skills

Issues live in this repo's GitHub Issues. See [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

The five canonical triage roles, each label string equal to its role name. See [docs/agents/triage-labels.md](docs/agents/triage-labels.md).
